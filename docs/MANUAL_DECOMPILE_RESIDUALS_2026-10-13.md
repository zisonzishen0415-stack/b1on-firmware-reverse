## 2. 五个硬函数(Overlapping input varnodes,三种简化风格全失败)→ 人工反编译

反编译器三个简化风格(decompile/normalize/firstpass)对该 5 个函数均报
`Overlapping input varnodes`。以下为逐条读 TI 反汇编后的人工分析
(汇编原文件:`work/retry_dec/man_<addr>.ti.txt`)。置信度标注:
[A]=结构清楚 [B]=语义推断。

### c0083158(A4=值, B4=缓冲基址, B5=索引) [A/B]
**位打包写入器**。状态变量全部在 B14 相对区:
`+30`(0xC00D0078,位置计数)、`+31`(0xC00D007C,相位 0..7 循环)、
`+128`(0xC00D0200,滚动掩码字节)、`+33`(0xC00D0084,清零)。
逻辑:相位==0 时把入参倍增写入掩码字节;否则把掩码高 1 位与入参
OR 后存入 `B4[B5]`,位置计数++,相位=(相位+1)&7,尾字节清零。
用途推断:向显示/段码缓冲按相位打包写入(每 8 次循环一轮)。

### c008f5f4(A4=值, B4=偏移) [A]
**命令缓冲写入器**:`if (B4 < 0x1400) *(0xC006D6C8 + B4) = A4; return 1;`
——0xC006D6C8 即命令分派器(f_c0090500)读取命令字节的同址!
0x1400=5KB 命令缓冲。

### c008ff14(A4=值, A6=串, B4=源块) [A/B]
**协议包构造器**:模板 0xC00DB898(6 字节)→ 0xC006EAC8 包头;
`[3]`←0xC00D0230 字节;`[6]`←入参低字节;`[7]/[8]`←计数器
`*0xC00D00CC` 的位段(>>25 / >>18)&0xFF,计数器++;`[9]`=23;
`[10..14]`=0;从 B4 拷 12 字节 → +15;再两次 `f_c008f614` 追加
两块(+30/+35);`+40` 写 0xF7 终止字节;最后 `f_c0082f2c(A6)`。
用途推断:编辑器/USB 查询包的组装(与命令缓冲 c008f5f4 同族)。

### c00c6460(A4=标志字节, B4=源1, A6=源2) [A]
**小记录组装器**(目标 0xC00DE2E0,RAM):`[4]`←A4;
从 B4 拷 4 字节 → +1..+4(SPLOOPD);从 A6 拷 6 字节 → +13..+18;
返回。19 字节记录。

### c00b45a0(A4=记录指针或 0, B4, A6, B6, A10) [A/B]
**48 字节描述符行填充器**:A4!=0 → `memset(A4, 0, 48)`,否则用栈上
临时(说明本函数可"就地填充或只计算");随后从全局
`0xC00DBA58/B944/B948/B94C/B950/B954/B958/B95C`(RAM 空洞)与
B14 相对状态读值,写入记录的 `+4/+8/+0xC/+0x10/+0x18/+0x1C/+0x28`
(与 48B 描述符行的字段布局一致);带多个条件出口(→ f_c00c7e80,
疑似"返回状态/让出"),期间对全局忙计数器 `0xC00DC0E4`(LHDU/STH)
做 +1/−1 包裹一个子调用(f_c00c7ea0)。
用途推断:从运行时状态生成/刷新描述符行(UI 元数据路径)。
