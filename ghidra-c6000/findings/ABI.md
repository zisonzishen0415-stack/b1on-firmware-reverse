# C6000 EABI 速查

## 调用约定

| 用途 | 寄存器 |
|---|---|
| 入参 1-10 | A4, B4, A6, B6, A8, B8, A10, B10, A12, B12 |
| 返回值 | A4;64 位 A5:A4 |
| 栈指针 | B15(8 字节对齐,向低增长) |
| 数据页指针 | B14(DP) |
| 返回地址 | B3 |
| 调用者保存 | A0-A9, B0-B9(除 B3/B14/B15) |
| 被调用者保存 | A10-A15, B10-B15 |

## 64 位值

- 寄存器对 `A5:A4`:低字 A4,高字 A5(小端)。
- 访存 `LDDW/STDW`:低字在低地址。

## 编译器生成的 helper

- `__c6xabi_divf/divd/divi/divu` 等(除法、long long 运算)。
- ZDL 内自定义 DSP 应避免这些 helper 或随模块自带。

## 数据模型

- 默认 `far_aggregates`:数组/结构体远数据,标量全局近数据(DP 相对)。
- ZDL 音频回调建议 `--mem_model:data=far`,拒绝 `R_C6000_SBR_*` 重定位。
